# إخراج APK من الجوال فقط

هذا المشروع يحتوي على GitHub Actions، لذلك يمكن بناء APK على خوادم GitHub بدون كمبيوتر.

## الخطوات
1. أنشئ حسابًا مجانيًا في GitHub إن لم يكن لديك.
2. أنشئ Repository جديدًا، مثل: `accounts-app`.
3. ارفع **محتويات هذا المجلد كاملة** إلى المستودع، مع الحفاظ على المجلدات.
4. بعد الرفع، افتح تبويب **Actions**.
5. افتح workflow باسم **Build Android APK**.
6. إذا لم يبدأ البناء تلقائيًا، اضغط **Run workflow**.
7. انتظر حتى تصبح العملية بعلامة نجاح.
8. افتح نتيجة التشغيل الناجح، ثم قسم **Artifacts**.
9. حمّل `AccountsApp-debug-apk`.
10. فك الضغط وستجد `app-debug.apk` وثبّته على هاتف Android.

ملاحظة: هذا يبني نسخة Debug للتجربة، وليس إصدارًا منشورًا على Google Play.
